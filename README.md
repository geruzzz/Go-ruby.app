# Go Ruby App (Full V1)

Next.js 14 App Router, Tailwind UI, World ID integration.
Contains single-page app with tab navigation: Claim / Stake / Swap / Donate.

**Important:** ABI files are NOT included. Add compiled ABIs to `/abis`.

Deploy steps:
1. Upload repo to GitHub
2. Add env vars in Vercel from `.env.local.template`
3. Add ABI JSON files to `/abis/`
4. Deploy on Vercel and test on mobile with World App.
